# LUMIÉ 공식 스토어

연성대학교 호텔관광과 과제로 만든 가상 브랜드 LUMIÉ의 쇼핑몰 홈페이지입니다.

- `index.html` 하나로 동작하는 정적 웹사이트예요 (서버 필요 없음).
- 상품 목록, 상세페이지, 장바구니, 주문서, 주문 완료(계좌이체 안내), 주문조회, 고객센터 화면이 있어요.
- 주문 정보는 브라우저 안에서만 처리되고 어디에도 저장되거나 전송되지 않아요.
- 일부 이미지는 AI로 생성했어요.

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소(Repository)를 만들어요. 예: `lumie-shop` (Public)
2. 저장소 화면에서 **Add file → Upload files**를 눌러 이 폴더 안의 파일(`index.html`, `README.md`, `images` 폴더)을 모두 끌어다 놓고 **Commit changes**를 눌러요.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 고르고 **Save**를 눌러요.
4. 1~2분 뒤 `https://<내 아이디>.github.io/lumie-shop/` 주소로 홈페이지가 열려요.
